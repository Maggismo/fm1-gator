GATOR

Firmware installer for the M-VAVE FM-1

GATOR turns the FM-1 into a monophonic macro-oscillator synth inspired by Mutable Instruments Plaits: 24 synthesis models from Plaits' open-source DSP code by Emilie Gillet, a low-pass gate, an ADSR envelope, two LFOs, an 8-slot modulation matrix and 16 presets.

At your own risk

Installing custom firmware is at your own risk.

GATOR is unofficial firmware, provided as is, without any warranty. It is not made, endorsed or supported by M-VAVE. A failed or interrupted install can leave the FM-1 unable to start until it is recovered with a USB tool. You can return to the official firmware at any time (below).

Before you install

  • Charge the FM-1: it runs on its battery while writing.
  • Plug the cable straight into the computer, no hub. It must be a data cable.
  • Close apps that use MIDI: DAWs, M-UPGRADE, editors.
  • Keep the computer awake (the page asks for that itself) and leave the cable alone until it says Done.
  • Use Chrome or Edge: Safari and Firefox have no Web MIDI with SysEx.

If something goes wrong

    

        
The write stopped: reconnect the FM-1 and press Install again. It stays in update mode until the write is
            finished.

        
The firmware does not start: after two failed boots in a row the FM-1 opens USB RESCUE by itself (or switch
            it on holding OCT−). The installer works there too.

        
If power is lost mid-write, the FM-1 may stay dark with no USB device: charge it before installing.

        
Recovering an FM-1 that does not start:
            MvaveFM1Unbricker

    


    
Back to the official firmware

    

        
Writes M-VAVE's FM-1 V15 the same way. Only the unmodified official file is accepted: its SHA-256 is
            checked before writing, and the file never leaves your browser.

        
Download FM-1 V15 (Downloads → PC Firmware):
            m-vave.com/download
